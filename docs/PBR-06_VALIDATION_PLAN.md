# PBR-06 Validation Plan

1. Verify each source flux independently, including basis, population/activity, organism/strain, culture conditions, uncertainty and time basis.
2. Validate oxygen and carbon dioxide inventories against independent closed-chamber gas analyser data with leakage quantified.
3. Validate atmosphere calculations against calibrated pressure, temperature and humidity sensors.
4. Validate crop carbon/water/nutrient balances against measured growth, harvest, transpiration and tissue composition.
5. Validate algal gas exchange against independently measured gross photosynthesis, respiration and gas-liquid transfer.
6. Validate microbial/waste mineralisation and nutrient recovery as separate unit processes.
7. Perform blind integrated holdout experiments, uncertainty propagation, sensitivity analysis and fault injection.
8. Conduct independent hazard analysis and review before any physical integration; human occupancy is outside this software milestone.

A numerical pass is not a biological or engineering validation result.
